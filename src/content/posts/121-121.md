eclipse中默认没有svn插件，而且网络环境不是太优秀时，在线安装插件比较麻烦，所以在此使用离线安装方式。

安装和配置subclipse的方法和注意事项可查看[相关wiki][1]。



我的eclipse安装信息：

    Eclipse IDE for Enterprise Java Developers.
    Version: 2018-12 (4.10.0)
    Build id: 20181214-0600
    OS: Linux, v.4.15.0-36-generic, x86_64 / gtk 3.22.30, WebKit 2.22.2
    Java version: 1.8.0_172

## 插件下载地址 ##
[https://dl.bintray.com/subclipse/releases/subclipse/][2]

## 离线安装方式 ##

 - 打开eclipse，Help > Install New Software...

 - work with 后的 manage...

 - 点击add

 - 点击Archive，选择下载的subclipse.zip，name那栏填写自己方便使用的名字，例如subeclipse

 - 完成后，再work with中填写上步中name拦内容，根据提示选择，可看到插件信息

 - 一路next即可

## 配置JavaHL ##

系统本身可能没有安装JavaHLL，参考[wiki][7]进行安装及配置

    apt-get install libsvn-java

安装完后，可通过locate命令查找具体安装路径

    locate libsvn

找到具体路径后，编辑eclipse.ini，在-vmargs后增加配置项

    -Djava.library.path=</path/to/library>

以上，重启后即可。
