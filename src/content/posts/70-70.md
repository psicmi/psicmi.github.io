注：以下操作均在 vmware 中的 ubuntu-server-16 TLS中进行。



1.首先将 server 正常关机，防止出现乱七八糟的错误。

2.通过如图所示的方法添加新磁盘

3.启动系统，切换到 root 用户

4.fdisk -l 查看新的磁盘

5.设置分区

    fdisk /dev/sdb

根据提示选择，最终写入磁盘；

6.格式化分区

    mkfs -t ext4 /dev/sdb

7.设置开机挂载,比如/docker

    vim /etc/fstab

    #添加一行
    /dev/sdb /docker ext4 defaults 0 0
