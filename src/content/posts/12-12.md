关于filebrowser
-------------

如其名曰，就是个文件浏览器，以web方式提供文件的浏览、上传和下载功能。当然，功能并不局限于此，它还可以执行脚本……



docker方式安装
----------

拉取镜像

    docker pull filebrowser/filebrowser

配置文件需要指定的路径信息：

Config: /etc/config.json
Database: /etc/database.db
Base scope: /srv

默认的配置文件内容：

    {
      "port": 80,
      "address": "",
      "database": "/etc/database.db",
      "scope": "/srv",
      "allowCommands": true,
      "allowEdit": true,
      "allowNew": true,
      "commands": []
    }

启动命令：

    docker run \
        -v /path/to/sites/root:/srv \
        -v /path/to/database.db:/database.db \
        -p 80:80 \
        filebrowser/filebrowser
